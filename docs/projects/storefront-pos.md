## Overview

Storefront POS is my commercial point of sale and inventory management product. My POS work includes building a system for a minimarket, integrating with a bank’s API to process payments, and keeping track of inventory.

## My Work

- Built retail workflows for processing sales and tracking inventory.
- Connected the POS with the bank’s API for payment processing.
- Developed a desktop application with **Electron** and **React**.
- Organized the application in a **Turborepo** monorepo, using **Vite**, **TanStack Start**, and **Better Auth**.
